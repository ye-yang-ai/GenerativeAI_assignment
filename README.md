# Generative AI Assignment

《生成式人工智能导论》课程期末项目。

本项目计划选择一篇近三年发表于 CCF A 类会议或期刊的图像或音频生成论文，复现其核心方法，并针对一个具体问题实现改进。项目将通过对照实验和消融实验评估改进效果，展示相同输入条件下的生成结果。

## 当前进度

- 已建立项目仓库并上传[作业要求](./generativeAI_assignment.pdf)。
- 论文选题、模型实现和实验尚未开始。

## 计划交付

- 基线方法与改进方法的训练代码、配置、日志和检查点
- 生成样例、定量评测结果及消融实验
- 实验报告和课堂汇报材料

论文信息、代码来源、环境安装、数据准备及运行命令将在选题和实现确定后补充。
